# Open Sign Web Co

Marketing site for Open Sign Web Co — a website-building business for small local businesses.

Built with [Astro](https://astro.build) and deployed to [opensignwebco.com](https://opensignwebco.com) via Cloudflare Pages.

## Stack

- Astro 5 (static output)
- Tailwind CSS 3
- TypeScript (strict)

## Commands

| Command         | Action                          |
| --------------- | ------------------------------- |
| `npm run dev`   | Start local dev server          |
| `npm run build` | Build to `dist/`                |
| `npm run preview` | Preview the built site        |
| `npm run lint`  | Lint with ESLint                |
| `npm run format` | Format with Prettier           |
